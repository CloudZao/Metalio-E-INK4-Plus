# Metalio-E-INK4-Plus
Metalio E-Ink4-Plus 是一款面向阅读与 AI 助手场景的开源墨水屏实体设备。整机搭载 4.7 寸 1216×684 并行电子纸（ED047TC2 / EPDiy + TPS65185）、FT6336U 电容触控、盖板虚拟键、冷暖双色前光、I2S 麦克风与扬声器（经外置蓝牙音频芯片）、microSD、片上 Wi‑Fi、SC7A20H 三轴加速度计、PCF8563 RTC、BQ27220 电量计、震动马达，以及 USB 摄像头 / 烧录通路切换能力。设备可通过语音与云端 AI 交互，并支持本地书库阅读、云端资源推送、待机壁纸、SD/U 盘存储与低功耗管理。

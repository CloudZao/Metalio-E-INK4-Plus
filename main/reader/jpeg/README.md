# 渐进式 JPEG 解码

`stb_image.h` 来自 https://github.com/nothings/stb ，固定版本为
`31c1ad37456438565541f4919958214b6e762fb4`（stb_image 2.30）。
保留上游完整版权及 MIT / Public Domain 双授权文本，第三方文件不作修改。

`progressive_jpeg.cc` 仅编入 JPEG，关闭其他图像格式、浮点接口、SIMD 和库内错误字符串。
共享图片入口仅将 SOF2 渐进式 JPEG 转交本模块；普通 JPEG 保持原解码路径。

- 支持常见 8 位灰度／三分量渐进式 JPEG，输出灰度 L8；不扩展到 12 位、算术编码或四分量图片。
- 原图单边受 L8 图片容器的 16 位尺寸表示约束，不再额外限定 4096 或 4 Mi 像素；实际能否解码取决于下述 PSRAM 预算。
- 系数、解码平面和完整灰度缓冲强制分配 PSRAM，单次临时分配不超过 8 MiB，并在每次分配前保留至少 2 MiB 空闲 PSRAM；并发请求串行执行。
- 最终缩放 L8 复用 RasterImage 容器，计入同次预算检查；超过 4 KiB 的结果若落入内部 RAM 则拒绝并释放。
- 文件输入缓冲只用 PSRAM，普通缩放入口最大 4 MiB，原尺寸入口按实际文件大小申请，独立于 8 MiB 解码预算；所有临时缓冲随同步调用结束释放，无常驻图片缓存。
- 渐进式即使仅生成缩略图也需要原图系数缓存；超预算返回失败，不向内部 RAM 回退。
- 等待互斥量、读取压缩流、分配及缩放行时检查取消；库内部已开始的计算段需自然返回，禁止强删任务。

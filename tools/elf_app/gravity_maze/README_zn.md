# 重力迷宫

**中文** | [English](README.md)

`gravity_maze.c` 实现独立 ELF 应用，`maze_engine.h` 维护地图、星星与碰撞逻辑。需要支持绘图、前台计时、加速度采样、应用内返回、推白切换、震动和音频接口的固件；旧固件缺少所需能力时拒绝启动。

## 界面

- 仅竖屏，按 684×1216 逻辑画布设计，顶部预留 54 像素模拟系统状态栏；ELF 按宿主实际内容区适配。
- 固定黑白样式。关卡选择、游戏、暂停、重试确认、通关及超时状态均可交互。首页右上角提供“设置”按钮，打开弹窗后可进入语言选择或开关音乐；语言支持简体中文与 English。设置和语言弹窗左上角返回上一级，不设取消按钮；音乐默认开启，应用私有存储保留开关状态。提示“倾斜设备，控制小球”紧贴标题右侧，同一行底部对齐；选择语言后返回设置；游戏中不显示语言入口，ELF 语言选择通过应用私有存储保存。暂停、重试及结果使用居中弹窗，标题和结果文字居中；弹窗高度按文字行与按钮数量计算，宽度按各类内容预留，背景保留迷宫并阻止操作。点选关卡直接进入，顶部紧凑栏保留关卡名称、倒计时、重试和暂停；迷宫占据其余主要区域，不显示步数、图例或操作说明。中英文使用相同布局，中文使用内置 25、30 号字库；小字与标题底部对齐并紧贴右侧，关卡箭头使用几何线段绘制。短按返回键从关卡回到关卡选择，从暂停或重试弹窗回到游戏，从关卡选择交由系统返回上一级。
- 三关及独立随机模式全部可直接选择；关卡名称为“初探”“回廊”“纵深”，地图分别为 7×11、9×15、9×15，限时分别为 60、75、90 秒。
- 地图由代码中的固定种子生成，最短路线依次为 50、56、76 步。随机模式为 9×15、限时 90 秒，每次进入或确认重试时生成新地图。首页不显示真实地图预览。

## 迷宫生成约束

固定关卡与随机模式均先生成不包含终点格的连通迷宫，再将终点作为叶节点接入，只保留一个入口。所有非终点格必须在不经过终点的情况下从起点到达，禁止出现只能经终点进入的无效支路或区域。星星遵循浅支路放置规则，不能放在终点之后。

## 玩法与时间

每个迷宫放置 5 颗星星，每颗 20 分，满分 100 分。小球进入星星所在格子后收集，重复经过不再计分；重试清空当前收集状态。星星优先放在通关路线旁支入口一格内，并沿路线分散；浅支路不足时放在主路上。收齐五颗星相对直接通关最多额外走 10 格。星星均可在抵达终点之前收集，不要求收齐才通关。首页仅在原得分位置分两行显示最高分、最近得分、最佳通关时长和最近通关时长，随机模式单独记录；得分在通关或超时后记录，通关时长仅在成功后更新，中途返回不写入成绩；游戏顶部显示当前分数，通关和超时弹窗显示本次得分。

- 按钮自动复用系统点击震动，遵循系统震动开关与点击反馈强度。通关或超时时单次震动 0.5 秒；暂停、重试确认和语言选择不触发结束震动。遵循系统震动开关，震动期间暂缓无操作待机，主动待机或退出可提前终止。
- 黑色小球从左上角出发，到达右下角圆环即通关。墙壁阻止移动，不扣时间，不统计移动步数。
- 设备进入或退出关卡先推白，目标画面物理刷新完成后再恢复前台计时与采样。暂停、确认弹层及页面隐藏时不计时；恢复后继续剩余时间。以单调时间计算，不按刷新次数计数。
- 重新挑战需确认，确认后清空当前进度并重新计时。可直接选择任意关卡；暂停与结束弹窗提供返回菜单；通关后可进入下一关或重试。
- 默认每 220ms 最多移动一格，无惯性、对角移动或穿墙。松开方向输入后停止。
- ELF 使用应用私有存储保存语言与各模式的得分、通关时长；兼容旧版最高分记录；重开后从关卡选择开始，不恢复进行中的对局。

## 设备操作

ELF 使用 SC7A20H 三轴加速度计，不提供陀螺仪角速度。开始和继续游戏时，以第一份有效样本建立握持基准；保持设备接近水平，向目标方向倾斜。X 正向向下，Y 正向向左。相对基准的 X/Y 变化经过一阶低通处理，主轴达到 150mg 且比另一轴大至少 40mg 时，每 220ms 最多移动一格。首次基准建立后再倾斜；直立握持会限制某些方向的可用变化范围。

游戏期间阻止无操作自动待机，仍允许电源键待机。宿主在待机或离页时停止应用采样，前台计时不计入待机；恢复后继续剩余时间。连续两秒没有有效样本时提示并暂停。退出后取消定时器、释放采样订阅和防待机需求。倾斜阈值及实际墨水屏移动手感仍需设备验证，浏览器不代表硬件刷新性能。

## 背景音乐

`music/` 保存五段原创循环音乐：主菜单“微光庭院”、第一关“纸间小步”、第二关“回廊轻拍”、第三关“纵深星轨”、随机模式“奇遇岔路”。格式为单声道 Ogg/Opus，输出 16kHz。构建时 `build_content.py` 按上述顺序生成 `assets.bin` 与字节范围头文件 `music_assets.h`；公共构建脚本将资源嵌入 ELF。播放仅请求对应音频范围，不把整包音乐载入 RAM。

音乐开启时，进入应用首页即循环播放主菜单音乐；进入关卡、重新开始、进入下一关和从关卡返回菜单时，从头播放对应音乐。打开设置、进入语言选择、切换语言以及从这些页面返回时，保持当前播放位置。暂停或重试确认时暂停，继续游戏时接着播放；通关、超时和退出时停止。设置和语言弹窗的返回按钮复用其他按钮的圆角与边框样式。

音乐开关只控制此应用，不修改系统音量；音量与系统统一，静音、系统设置和音量键直接生效，不提供独立音乐音量。音频失败时显示提示，游戏仍可继续。宿主接口与 SD 文件播放用法统一见[音频开发说明](../README_zn.md#音频播放xz_app_cap_audio)。

## 构建与安装

按[开发手册](../README_zn.md)配置工具链后执行：

```powershell
./tools/elf_app/build_app.ps1 -Compiler $compiler -AppDirectory ./tools/elf_app/gravity_maze
```

构建脚本输出 `gravity_maze.elf`，内含 128×128 黑白图标。手动复制到 SD 卡时，交付文件名为 `重力迷宫.elf`，与 `manifest.json` 一起放入 `metalio/e-ink/apps/重力迷宫/`。清单的 `installedName` 必须为“重力迷宫”，大小与 SHA256 必须匹配所复制的 ELF；重新编译后需同步更新清单。也可使用应用商店现有上传和安装流程。更新宿主固件不会自动替换 SD 卡中的应用。


### 重力迷宫：能力组合与兼容失败

[重力迷宫](README_zn.md) 的 `app_main` 先检查 ABI、`audio_get_status` 字段边界、所需能力位和函数指针，再查询音频格式、来源、采样率与声道。必需能力缺失时返回 `XZ_APP_ERR_UNSUPPORTED`，在注册回调或创建界面前结束。可选能力可以降级，但不得先访问不存在的尾部字段。

示例中 `DrawMaze` 组合绘图指令，`Tick` 读取加速度并以 `foreground_ms` 计算游戏时间，`Back` 处理应用内返回，界面切换请求推白，结束反馈调用 `vibrate(..., 500)`。`MusicStart` 使用资源分段偏移循环播放五段 Ogg/Opus，`build_content.py` 生成资源与偏移头；暂停与继续复用音频会话，设置返回保留播放位置。私有存储保存语言、音乐开关、得分和通关时间；退出与待机的资源、采样及音频生命周期由宿主管理。接口参数和限制以上述各能力章节为准。


当前入口要求内容区宽度至少 500、竖屏且高度不超过 1600；当前 397 内容区宽度不足，不因生成 Xtensa ELF 而自动获得适配。

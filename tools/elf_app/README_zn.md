# ELF 应用开发工具与示例

**中文** | [English](README.md)

编写规则、ABI 与生命周期、资源格式和计算器入门步骤统一见[开发手册](DEVELOPMENT_zn.md)。构建脚本、公共辅助头和应用示例集中在本目录；固件运行时和权威接口仍位于 `main/app_store/`。

应用使用 `main/app_store/app_api.h` 的 ABI 1，在设备提供的内容区创建控件。各示例通过入口检查所需能力；使用扩展接口的应用需要配套固件。应用不得在退出后保存宿主引用或留下后台任务。

## 能力概览

宿主管理基础控件、黑白绘图、时间与前台计时、定时器、私有数据、三轴加速度、限时震动、应用内返回及推白切换。按钮点击反馈遵循系统震动设置。

音频支持 ELF 内置资源及 SD 文件的 Ogg/Opus、PCM WAV 播放，可循环、暂停、继续、停止并查询进度，音量与系统统一。录音支持单录音槽的开始、暂停、继续和停止保存，输出 16kHz、单声道、16 位 PCM WAV，保存后可直接回放；成功保存新录音才覆盖上一条。录音与播放互斥，不提供多录音文件管理。

应用退出时宿主清理资源；唤醒画面物理刷新成功后才恢复前台业务。新增能力仍使用 ABI 1 尾部扩展，应用必须按字段边界、能力位和函数指针检查兼容性。具体参数与限制统一见[开发手册](DEVELOPMENT_zn.md#5-能力接口)。

## 应用示例

- `calculator`：标准计算器，支持小数四则运算、百分比、正负切换、退格、连续计算与重复等号；显示 12 位有效数字，按从左到右顺序计算，不应用运算符优先级。
- `unit_converter`：长度、质量、温度和面积换算，直接选择来源与目标单位，支持小数、正负切换、交换单位和 12 位有效数字显示；温度低于绝对零度时提示无效。
- `calendar`：1600—2399 年公历，按月或年浏览、选择日期、标记今天并返回今天。启动和点击“回到今天”时读取设备本地日期；设备时间未就绪时从 2000 年 1 月开始手动浏览，不标记今天。
- `base_converter`：32 位无符号二、八、十、十六进制同步换算，二进制按字节分组，禁用无效数字并在溢出时保留原值。
- `english_reader`：章节阅读、206 个词汇卡片及选择练习，阅读位置仅保留在当前运行期间。英文原文为 Lewis Carroll 的《Alice’s Adventures in Wonderland》，来自 [Project Gutenberg ebook 11](https://www.gutenberg.org/ebooks/11)；原始文本保存在 `book.txt`，完整许可作为阅读附录保留。
- `package_check`：包含 16 MiB 确定性资源，用于验证大包下载与 SD 按需读取。运行时抽样校验首部、中间和尾部共 17 段；安装时的 SHA256 校验覆盖完整文件。

- `pomodoro`：以大号倒计时为主的离线番茄钟。单屏提供专注、短休息、长休息切换，以及开始、暂停、继续和重置确认。默认 25 / 5 / 15 分钟，每四轮专注进入长休息，不包含目标输入、统计或设置页面。更新保留原有时长与进度；离开时保存并暂停，重开后手动继续。
- `recorder`：单文件录音与回放示例，支持暂停、继续、停止保存、时长及播放进度；重新录音成功后覆盖上一条，使用应用私有数据与临时目录，详见[应用说明](recorder/README_zn.md)。
- `gravity_maze`：竖屏重力迷宫，三关与随机模式、限时挑战、五颗星计分和中英文界面；演示内置循环音乐及系统音量，需绘图、前台计时、加速度及音频能力，详见[应用说明](gravity_maze/README_zn.md)。

使用 ESP32-S31 RISC-V 工具链构建，先将 IDF Python 加入 PATH，再运行：

```powershell
./tools/elf_app/build_app.ps1 -Compiler <riscv32-esp-elf-gcc.exe> -AppDirectory ./tools/elf_app/package_check
```

脚本生成 ELF、嵌入图标，并在提供 `build_content.py` 时生成内容；构建只允许 `main/app_store/app_runtime_math.def` 中登记的编译器运行时导入。新版计算器需要包含该运行时清单和可选控件样式接口的固件；新版万年历、进制换算和单位换算需要支持按钮文本更新与禁用功能的固件。`package_check` 的 `assets.bin` 和 `english_reader` 的 `content.h` 为构建产物。将 ELF 上传到本地服务并上架后，可从设备安装；无需将应用内容打入固件。

应用开发接口与能力检查、托管定时器、私有数据、输入控件和退出清理的约定见[应用商店开发说明](DEVELOPMENT_zn.md)。新应用须检查可选字段与能力，不依赖新增接口的旧应用继续使用 ABI 1。

番茄钟需要基础能力接口及 `XZ_APP_CAP_KEEP_AWAKE`，旧固件会拒绝启动；配套固件升级后再安装使用。运行时阻止无操作自动待机，不保网，暂停或退出时释放；电源键主动待机仍由系统处理。每分钟及关键操作时保存快照，断电可能丢失最近一次快照后的进度。提醒仅在前台以屏幕提示显示，不提供后台响铃。

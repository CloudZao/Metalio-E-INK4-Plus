# Plus 产品交互默认

这是面向用户体验的内部模块，不是固件口袋最低接入协议。新应用需求/UI阶段先读本页；用户明确需求与默认冲突时调整对应体验，保留真实存储、硬件安全和双模式协议。

- 默认中文：应用显示名、简介、帮助、退出说明、错误提示和交付说明。代码标识符与兼容ID不翻译；用户明确指定其他语言时采用指定语言。
- 顶栏左：应用名 → **返回口袋**。右侧从左至右：帮助 → **研墨** → Wi-Fi（仅有联网功能时）→ 电池。新开发优先可见返回按钮；独立运行隐藏并回收布局/命中空间，不保留死按钮或空洞。不以组合键作为新应用默认出口。
- 电量是真实读数，未知显示未知；数字在紧凑电池内。Wi-Fi凭据存在、连接中、有IP、业务请求成功是不同状态。标题按真实字体截断，不挤掉动作。
- 通过安全门的每次合法新触摸按下短震一次，含空白/禁用区；持续按住、滑动采样、松开不重复震。反馈是“接收触摸”，不是业务成功。锁屏、深休、Flash及陈旧事件门禁保留，UI/IME不重复补震。
- 运行最低稳定非零前光；短按电源锁屏/恢复，锁屏熄灯、保留会话。连续长按5秒进入真实深休；连续长按至少5秒才放行唤醒。休眠提示中文且与实际动作一致。
- **10分钟无有效按键/触摸自动深休**。用户明确启动的长录音/播放等长任务期间暂缓，全部结束后重新计时；唤醒后重新计时。定时刷新、轮询联网、日志和触控噪声不续时。与手动深休共用可靠保存、任务结束、实际画面完成、熄灯流程；失败保留数据，不硬切电或谎称保存。
- 日常无按次数/时间的自动全刷；用户研墨即使画面未变也全刷、业务不变。允许首屏建立状态、未知屏态、实际失败有界恢复、灰阶海报进入/退出的必要完整刷新。不要把例外扩展成每页/每击全刷。
- 帮助说明实际功能、配网/存储、锁屏/深休、返回方式；能查看实际使用的第三方许可完整内容，随交付保留许可文档。原型说明、调试标记不进入产品UI。

实现路由：[设备交互](../device-interaction/MODULE.md)、[字体](../font-support/MODULE.md)。`plus-app-base/main/app_view.h`给出顶栏、共享命中、中文和可翻页许可的生产示例；`app_lifecycle.h`给出idle及异步帧状态。它们是可改造的能力示例，不能当成用户业务已完成。口袋最低接入字段与事务只读[口袋模块](../pocket-integration/MODULE.md)，不把产品偏好写进ABI。

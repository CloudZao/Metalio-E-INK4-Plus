# Noto 原生黑白字体

Plus 4.7英寸的内部能力模块。优先复用本包预生成字体与生产C++读取器；普通接入不下载TTF、不安装Pillow，也不重写生成器。原生稍实112已获源样本用户认可，字号和字重依布局选择，通常从32px/500开始，尊重已确认需求。

先读[Windows接入](references/windows-font.md)。本包有24/28/32/36/40/48px × 400/500/600，共18套7056码点；固定字源、摘要、工具与精确字符表在`assets/fonts/`。菜单可裁剪；记事本、网页等自由文本保留完整选定规格并检查业务码点，不把“7056”宣称为全Unicode。

`scripts/prepare_font.py`仅用Python标准库，产出font.cc/font.h/font.ntf、来源摘要和OFL/NOTICE；只把选定规格编入一次。需要新增字号/字符再读[字源重生成](references/regeneration.md)。原生保留bearing、advance和共同baseline，不逐字塞旧框，不运行时缩放，不再描边/膨胀。

组件MIT；Noto及衍生字库OFL1.1，分别见`LICENSE`和`licenses/`。应用帮助/许可页必须实际引用完整许可，源码和交付文档同时保留；MIT不覆盖字库。字体只画内存，不管理触摸、电源、刷新、口袋或输入法。

验证范围：18套资源及独立边界有既有主机证据，旧445×18样本与用户已接受测试字形/度量一致；不是127008字形逐字真机验收。V0.2原生Windows的生产帧/布局检查入口在设备模块，目标构建与新应用真机显示仍单独记录。

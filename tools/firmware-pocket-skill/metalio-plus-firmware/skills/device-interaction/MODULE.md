# Plus 设备交互

这是主 Skill 按需读取的内部模块，不要求宿主单独注册。目标为 ESP32-S31 的 Plus，使用当前工程的实际板级驱动；3.97 寸的屏驱、引脚、镜像、坐标和 SDK 配置不能直接套用。

先读 [设备档案](references/plus-hardware.md) 与 [产品交互默认](../product-conventions/MODULE.md)。新应用使用 [实际Plus底座](../firmware-build/references/plus-app-base.md)；UI落地读 [共享生产绘制与命中](references/ui-on-device.md)，字体读 [Noto模块](../font-support/MODULE.md)。刷新/素材读 [显示与资源](references/display-assets.md)，触摸/电源读 [设备状态接法](references/touch-power.md)，存储/联网读 [对应入口](references/storage-network.md)，声音/动画才读 [音频与动画](references/audio-animation.md)。文字编辑另读 [文字输入](../text-input/MODULE.md)。无网络/声音需求不增加相应业务框架。

## 对用户可见的默认结果

- 中文原生像素字体；左侧标题后返回口袋，右侧帮助、研墨、可选真实Wi-Fi、电池；独立模式回收返回入口。详细默认只维护在产品规范。
- 日常DU与主动研墨，保留已明确的首屏/未知屏态/失败恢复/灰阶切换全刷例外。
- 合法新触摸按下短震一次，包含空白和不可用控件；震动不表示业务已经执行。锁屏、Flash 和场景边界仍有门禁。
- 最低微光、短按锁屏、5秒深休/唤醒及10分钟无操作自动深休。用户长任务暂缓自动深休，完成/唤醒重新计时。口袋专属数字密码不属于应用。
- 存储、网络和可选服务分别报告真实状态。失败不伪造保存、联网、识别文字或成功返回，不把业务数据与口袋控制记录混为一处。

这些是本版新应用目标；历史某个 BIN 通过测试，不代表本次新应用已实现。按用户明确需求调整布局与功能，不把某项目的字号、目录、刷新次数或声音系数变成设备定律。

## 实现时保留的边界

输入事件、业务状态、软件绘制、物理刷新分层：可以合并尚未显示的中间帧，不能合并字符、点击或保存。只在完整画面实际显示后发对应完成回执；锁屏控制画面不能推进业务帧回执。Flash 擦写及启动校验沿用显示互斥门，错误路径释放资源。

先选择能满足需求的 UI/HAL，不强制 LVGL，也不因精简而删除互斥、错误恢复、中文覆盖和存档。不复制整套旧应用来获得一个按键或一个字形功能。

## 最小验收

主机能验证坐标、字符覆盖、图像长度/反解、事件状态、文件格式和取消代次；目标编译验证实际 SDK 与驱动接口。真实启动、点按、实体按键、灰阶/残影、录音/听感、深休恢复与保存返回需对应设备证据。未测试项列为待验收，不用截图、计数或旧版本接受替代。

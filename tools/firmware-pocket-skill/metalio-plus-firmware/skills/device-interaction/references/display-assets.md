# 显示、字体与静态资源

适用：Plus 静态 UI、锁屏海报、深休图。动画另读音频与动画文档。关键词：原生像素、字体覆盖、DU、GC16、完整帧、packed、资源长度。

## 字体和布局先落到实际像素

物理面板1216×684，竖屏逻辑画布684×1216。优先用包内[Noto原生字体](../../font-support/MODULE.md)，已固定字源/OFL及稍实112；按布局选字号字重。保留真实advance、bearing、基线与行高，不放大旧小屏位图，不把旧MiSans字框套到Noto。具体覆盖和许可随实际字体走。

静态中文、键盘标签、动态输入/联网内容的覆盖范围分别统计。自由文本不能使用只够测试几页的微小字集。启用本包拼音词表时，字体须覆盖全部 4262 个可输入汉字；候选表不是字体。缺字应报告并补字，不静默删候选。数据源若允许任意网页文字，可明确回退字形及不可覆盖字符，不宣传全 Unicode 支持。

字形 1 bpp 可降低 Flash 成本，前提是与选定覆盖阈值逐像素等价；字体 alpha 阈值、图片灰度阈值不是同一个参数。字浅先看缩放、覆盖率和输出模式，不先改 VCOM。预览尽量来自实际生产 renderer 或同一像素数据；独立绘图库的样张不能证明真实绘制链一致。

## 静态页面默认刷新

首屏全刷建立已知状态；日常翻页、输入、弹窗、状态变化优先DU黑白快刷。顶栏右侧“研墨”清屏并全刷当前画面，即使像素没变也执行，业务数据不变。普通redraw不等于full，场景/触摸失效也不自动全刷。允许未知屏态、真实失败有界恢复与灰阶海报必要切换，不借例外恢复每页/每击/定时全刷。

浏览器 `1.1.0-plus.2` 用户实测接受了首屏全刷、日常快刷和手动研墨，移除了旧的每 48 次局刷自动全刷规则；不要又把历史 48 次阈值当成本版统一默认。面板未知状态和真实刷新失败仍要有有界恢复。静态灰阶海报可使用完整 GC16，退出海报要清理灰阶目标；不要把整应用强行黑白化。

异步内容加载合并中间状态：快结果直接显示，慢请求显示一次可取消提示；不为每个内部阶段刷一帧。过去的 800 ms 等待是应用参数，不是设备常数。只测量真实物理刷新完成；不用周期定时器、已入队或像素相同跳过次数冒充帧率。

## 完整帧与 Flash 门

画面链建议为：UI 绘制到 render → 最后条带结束 → 在帧锁内复制完整 pending → 显示 worker 取私有前帧 → 物理完成后确认对应代次。传输期间不可覆写驱动正在读取的帧。可合并 pending 到最新完整帧，不可用逐条带通知模拟整帧。

准备 Flash/NVS 写入、OTA 确认或长时间 Flash 哈希读取前，让必要提示画面真正显示，再取得同一物理显示闸门；错误路径也要释放。仅禁止 UI 绘制不证明底层已经停止送行。业务显示回执和锁屏/深休控制回执分开，控制画面不得清除业务失败或推进业务启动确认。

默认示例`main/app_lifecycle.h::FrameFlow`与main已经分离输入消费和物理等待：输入立即更新业务，HAL忙时延后绘制，完成旧帧不吞新dirty；切页命中待真实显示后放行。不要把旧冒烟页逐触摸等待Present的写法复制为正式业务循环。

## 两种 Plus 原生资源合同

| 格式 | 画布与大小 | 编码与消费 |
| --- | --- | --- |
| `native4` 静态灰度 | 1216×684，415872 字节；每行608字节 | 偶数 x 低 nibble、奇数 x 高 nibble，0黑15白；直接复制原生 framebuffer。 |
| `mono1` 黑白 | 1216×684，103968 字节；每行152字节 | MSB-first，1=黑；消费端按约定展开到原生帧。 |

竖屏宽684不能直接按整数逐行字节打包为1bpp；先按 `(physical_x,physical_y)=(logical_y,683-logical_x)` 转到物理1216行宽。尺寸、格式和符号长度必须一起传递；不要凭变量仍叫 lockscreen 推断格式。

资源处理：原件只读 → 一次适配最终尺寸/比例 → alpha 合成与边缘处理 → 灰度量化 → 按目标方向打包 → **从最终 packed 字节反解** → 逐像素一致检查。量化后不再缩放。灰度码有16种不等于真机光学实测16阶；沿实际 waveform 绑定、GC16 分支、LUT 和消费函数核对真实链路。

本模块提供不依赖图像库的确定性编码器 [pack_plus_pgm.py](../scripts/pack_plus_pgm.py)。输入为已经完成设计、缩放和白底合成的 P5 8-bit 灰度 PGM；脚本只做格式转换，不替代素材设计、抗锯齿、字形确认或真机验收。

```powershell
python "$DeviceModule\scripts\pack_plus_pgm.py" --input "$Work\lock.pgm" --orientation portrait --format native4 --output "$Work\assets\lock.native4.bin"
python "$DeviceModule\scripts\pack_plus_pgm.py" --input "$Work\deep.pgm" --orientation portrait --format mono1 --threshold 160 --output "$Work\assets\deep.mono1.bin"
```

`$DeviceModule` 指本模块绝对路径，`$Work` 指任务工作目录。输入 portrait 必须684×1216，landscape必须1216×684。输出旁生成反解 PGM 和 JSON 摘要；阈值160只作为明确调用的示例，不是通用字体阈值。转换后的实际嵌入符号、长度、Init guard 和显示消费路径仍需检查；静态资源编码通过不等于固件启动通过。

## 不漏掉启动合同

变更格式时同时检查生成器、manifest、CMake 嵌入、实际链接符号、消费分支、启动长度 guard、锁屏/深休/恢复所有路径。一次真实历史故障是锁图升级415872字节native4后，Init仍要求两张图均103968字节，导致在显示和业务初始化前失败；“BIN存在、资源存在”都没发现该问题。对实际待交付字节运行生产 guard，而非测试里复制一条相似公式。

已接受的静态灰度素材来自森林 `1.0.0-plus.8` 的用户整体验收；不外推任意温度、面板批次、全部灰阶可分辨度或长期残影。新应用交付分别记录像素检查、目标构建、启动、真实显示结果。

# 数据保存、外部文件与网络

按需求阅读：无数据应用只需确认口袋的 NONE 存储合同；有业务保存读前两节，有联网读最后一节。不为所有应用增加TF、云端、账号或迁移系统。

## 业务档和控制档分开

先决定：无持久化、Flash状态或应用自管TF；对应口袋声明读取 [集成模块](../../pocket-integration/MODULE.md)。AppID识别应用、用户ID表达归属、实例ID识别一份业务世界，三者不可混用。更新展示名/版本不顺手换AppID。按需求明确独立与集成是否共档、卡级共享还是多用户隔离，不因启动模式暗中切换业务根，造成“原数据消失”。

浅业务目录便于用户和外部应用发现，但目录字面值由应用决定。新独立卡不为业务档伪造口袋身份；集成运行仍验证真实身份、镜像和本次run。口袋的run、started/saved仍属于控制合同，不因业务改到浅目录一起搬走。

保存成功必须有真实持久化结果：检查write/短写、flush、fsync、close及读回；适合小状态的双槽记录覆盖非最新槽，格式/代次/长度/负载都进入校验，成功才发布新状态。CRC不是业务语义或多文件事务保证。先保存权威业务，再写保存回执，再返回口袋；失败不伪造saved。

外部文件采用有界解析，校验路径、类型、层数、数量、单文件/总容量及UTF-8；文件名不作为可信路径拼接。文本编辑按字节预算与完整Unicode边界，失败不截断汉字或丢草稿。输入法不负责业务持久化。

### TF与USB

TF只有一个所有者。开启MSC前关闭业务文件；电脑安全弹出后，还需设备停用MSC、移除存储并恢复VFS挂载，应用才读写。盘符消失不证明设备已恢复挂载。不为挂载失败自动格式化、擦卡或复制整卡隐私数据。

容量查询核对目标SDK实际支持：本设备曾有 `statvfs` 编译成功却运行返回ENOSYS，FatFs `f_getfree` 可取当前卷容量。按空闲簇数×簇扇区数×实际扇区字节数用64位算并检溢出；配置最大4096不代表卡实际4096。播放只读需求与录音可写空间分开。

## 只在需要升级或跨应用协作时展开

迁移是受控复制：先列旧源、新目标与冲突策略，检查新档；有有效新档按已定策略使用，不能偷偷混入旧进度。同代不同内容、不同实例、不同交互树要明确冲突，不能猜“最新”。先复制完整必要树及权威状态，逐文件核对，再写迁移完成标记；半途失败保留现场和旧档。

迁移成功的旧源成为备份，不持续双向同步。用户后来明确重置新业务档时，不自动将已经完成迁移的旧档灌回；新实例隔离旧事件。删业务数据、解除一次口袋交接限制、擦除芯片是三个动作，不用删除整个 `firmware-pocket` 代替处理。

跨应用文件可发现不等于能协作。指定权威主档单写者、外部只读快照、事件schema、实例、递增序号与回执。同一事件ID和相同内容可幂等重试，同ID变内容拒绝；先持久化状态和去重回执再消费事件。临时文件在同目录写完同步后发布，不把多个文件的改名当成原子事务保证。

这些方法有森林plus.6迁移主机测试和plus.8整体验收来源；真实TF异常断电、任意坏卡和跨应用组合未因此全部通过。新应用只为实际需求实现对应能力。

## 网络层次与外部服务

Wi-Fi关联、取得IP、校时、DNS/TCP/TLS、HTTP状态、响应格式、业务结果分别判断。API失败不把Wi-Fi图标改成断网，保存了密码也不显示已连接。公共Wi-Fi候选与应用权威配置按口袋协议处理，不将“候选存在”当作可直接执行的完整授权或有效配置。

网络请求放后台，设超时、取消、正文/解压上限、状态与代次；读完或正确排空响应缓存。过期的连接结果和页面结果不能覆盖新任务。错误消息有帮助但不泄漏密码、token或响应中的敏感数据。天气城市与兜底按用户需求，不硬编码历史深圳兜底到所有天气应用。

有IP而HTTPS失败时先检查RTC与校时来源，不以关闭证书/域名检查修复。历史公开天气接口曾用有界HTTP HEAD Date和SNTP作时间提示；这些是未认证时间，不适合作为所有敏感业务的可信授时方案。若选择该方案，严格校验完整日期、范围/闰日，保持TLS根证书、主机名与有效期检查，并说明适用范围。

地址、密钥和服务身份在实现时按所选提供方核对。官方固件能聊天，不意味着新独立固件拥有同样的服务授权/额度；物理MAC、客户端UUID和供应商凭据不同。没有用户提供的服务配置时明确“未配置”，不得制造成功响应或为凑演示上传数据。

主机用可控响应检查超时/格式/取消/限额，真实网络检查记录实际路由与状态，但不把测试fixture当成联网成功。新增业务依赖的下载按主流程记录来源、版本与耗时，不影响冻结基础材料身份。

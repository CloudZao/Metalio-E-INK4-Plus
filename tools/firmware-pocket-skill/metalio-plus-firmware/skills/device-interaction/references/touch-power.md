# 触摸、顶栏与电源状态

适用：Plus 新应用通用交互。以下约束优先于旧示例中的三秒关机、逐控件震动或周期全刷。具体控件库、线程名和队列尺寸可由宿主选择。

## 顶栏与导航

产品顺序以[产品交互默认](../../product-conventions/MODULE.md)为准：左侧标题→返回口袋；右侧帮助→研墨→可选Wi-Fi→电池。`main/app_view.h::MakeLayout`同时供绘制和命中，独立模式返回矩形为空并回收空间。标题按真实advance截断，未知电量不填假数，联网状态与API结果分开。

返回内容菜单与离开应用使用不同文案。集成运行时“返回口袋”要走保存与交接；独立运行不显示不存在的宿主入口。已有必要退出确认继续复用，不叠加多轮确认。研墨、锁屏不清空草稿或返回首页。

## 输入不等物理显示

采样 → 有界 Down/Move/Up FIFO（坐标、时间、场景代次）→ GUI逐条消费 → 业务状态。显示合并完整帧，马达独立调度。相邻 Move 可合并，Down/Up 不可被最新单点覆盖。LVGL 接入时使用其逐条读取机制；不用单点快照抹去两次GUI轮询之间的完整短按。

队满需要明确溢出处理，保留松手能力；取消旧手势、推进代次、等待可信释放，不留孤立Up触发旧按钮。切页、弹窗、锁屏和Flash边界失效旧事件；普通字符更新不能重建整页、重置整个输入场景或丢掉排队字母。弹窗不穿透底下控件，禁用控件可见但不执行业务。

触摸报告规范化：count0是可信无触点；同ID显式UP可结束活跃手势；重复DOWN不重复点击，CONTACT不变连击；多指、ID突变、无效报告不冒充全部松手。采样暂停前后用代次拒绝跨界I2C结果，释放驱动锁后再回调GUI。屏外盖板键单独分类。

面板忙时可延后软件光栅化，但不暂停全部 `lv_timer_handler`、输入或业务定时器。场景尚未显示时应允许生成它的第一帧，避免“ScenePending所以禁止绘制”的自锁。字体缓存有界并保持像素一致；输出缓冲归消费者拥有，不把可被淘汰的槽指针直接交出去。

### 全触点短震和输入成功不是同一状态

当前Plus交互以**通过安全门的合法新DOWN**为一次短震触发点，空白和不可用控件也反馈，持续按住或滑动不重复。优先在HAL统一发起，移除UI/IME重复Pulse；手工键盘不能再按每次字符补震。被锁屏、Flash、过期场景拒绝的事件不补发，唤醒先松手再武装。

队列入队/马达驱动调用不证明机械短震完成。不要把旧示例22ms、口袋30ms或一个tick当成保证的真实时长；有最小停顿要求时从成功关断后的单调时钟核验。共享Port0写保持其他位，错误返回要真实，GUI不得等待马达或I2C辅助锁。

文字候选、动态确认键等随画面变语义的动作，还须通过已显示版本检查，详见文字模块；触摸有震动不代表该候选已提交。

## 电源状态合同

| 状态/操作 | 行为 |
| --- | --- |
| 运行 | 业务界面可操作，前光为板级确认的最低稳定非零值。 |
| 运行短按并松开 | 显示本应用锁屏海报，熄灯，禁止触摸及不适合锁屏的实体键。 |
| 锁屏短按并松开 | 恢复业务帧，物理恢复成功后重武装输入，恢复微光。 |
| 运行或锁屏连续长按5秒 | 请求保存，完成深休画面，熄灯、配置唤醒、实际深休。 |
| 深休短按/触摸 | 不显示正常业务，不点亮前光；保持休眠语义。 |
| 深休连续长按5秒 | 早期唤醒门确认后进入业务，读取持久化存档。 |

锁屏是保留会话的运行状态，不等于深休。后台录音可按业务继续采样、到时保存；不能为通用锁屏把全部业务强制暂停。深休前则要结束需要关闭的音频/网络任务并可靠保存。口袋的数字唤醒密码属于口袋自身，不给每个应用增加密码功能。

按键计时只累计成功连续采样；读取失败、大采样间断或时钟异常取消这次长按。达到5秒只发一次事件，松手不补短按；启动、唤醒、锁屏和Flash边界后先确认松手。电源采样任务只投递请求，保存/显示/断电由协调层执行。

深休推荐顺序：停止必要业务更新 → 完成持久化并读回 → 等待已接收帧结束 → 提交深休画面并等待物理成功 → 熄灯 → 确认进入动作已松手 → 卸载/释放资源 → 配置唤醒 → `esp_deep_sleep_start`。失败保留真实错误及可恢复状态，不能只贴图就宣称低功耗；USB仍占TF时先交还所有权。

唤醒确认放在正常UI、网络与前光初始化前；底层短按已触发CPU唤醒也不代表允许业务启动。早期阶段只启用检测按键所需硬件，确认不足5秒则回睡。RTC标记、唤醒源和板级共享中断必须核对；普通业务循环无法在真正深休期间计时。不承诺未经测量的休眠电流或续航。

## 自动深休与组合状态

`main/app_lifecycle.h::IdleSleep`用64位单调微秒，默认10分钟；HAL的`LastUserActivityUs()`只记录合法人机事件，后台刷新/定时联网不更新。主循环观察锁屏/恢复代次，唤醒重新计时；锁屏也继续无操作计时，不从主循环跳过电源请求。

用户主动开始的长录音/播放用`BeginUserLongTask()`；任务真正结束、资源已释放才`EndUserLongTask(now)`，全部长任务结束重新计时。定时网络刷新不能挂一个永不释放的长任务标记。深休先停止任务，保存成功，再调用HAL PowerOff；手动和自动同一路径。失败后保留状态并有界退避，不每帧重复写TF。异步服务读[任务生命周期](../../app-capabilities/MODULE.md)。

组合检查用生产helper：刷新在途后新输入、切页旧点击、锁图成功不推进业务回执、锁屏后长按、保存失败拒绝深休、5秒后松手不补短按、10分钟边界、长任务延期结束/唤醒重计时。设备电流与真实触感仍须真机，主机时间注入不代表设备已经验收。

## 分层检查与证据

触摸故障依次看控制器原始报告、FIFO/坐标、GUI状态、业务接受、软件绘制、物理完成。LVGL9相关按钮按下即重启的已知修法：不要用 `lv_obj_set_style_transition(..., nullptr, ...)` 表示禁用；它可能登记空描述符并在状态切换解引用。需要移除本地属性时用 `lv_obj_remove_local_style_prop(..., LV_STYLE_TRANSITION, ...)`，保留主题时另查继承样式。

取证限定同一轮输入，记录前后计数差、接受文本与拒绝原因；累计最大延迟不能相减当本轮最大值。日志默认只含计数、耗时和状态，不记录密码、正文或候选。测试点击与拖动、跨页旧手势、弹窗、快速输入、实体键、锁屏/唤醒/长按；主机状态机通过与用户真机触感分开。

证据边界：独立触屏D测试和口袋plus.11曾获用户接受；plus.12全触点短震获确认；口袋plus.7/plus.8的5秒深休及唤醒有源码、主机和用户证据，后续版本保留。它们支持方法复用，不证明任何新应用任意速度零丢键、零漏震或已实现深休。

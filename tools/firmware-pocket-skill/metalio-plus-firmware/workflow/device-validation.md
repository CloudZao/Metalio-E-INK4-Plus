# 设备验证与交付边界

默认USB串口可用，先识别目标设备与端口，确认本次用户授权的烧录/重启范围；不要因为能连接就擦写其他设备或口袋管理固件。无串口继续生成BIN，逐项标记未做真机验证，不能用主机测试替代机械震动、屏刷、电源和真实Wi-Fi。

优先最小硬件探针确认方向/显示/触摸/光/按键，再验证用户业务；可复用近期同设备同底座证据，新增组合仍验证受影响路径。最终两态都检查：独立启动配网/保存/恢复；口袋识别/启动/公共配置/返回/恢复。不要把独立整机prefix与应用分段混用。

验收至少覆盖核心需求、真实数据、长文字与触摸、保存失败保原稿、刷新中锁屏、长按松手不补短按、后台取消后迟到结果、手动研墨保持业务、10分钟空闲/长任务结束重新计时、中文帮助/退出及许可可读。选择与该任务相关项，避免测试不使用的能力。

记录机器可观察的串口、屏帧、文件、哈希和用户反馈来源；把“用户实测”“日志”“源码审查”“主机测试”“未验证”分开。首次不通过保留现场，在授权范围内修复并复测，再交付最终BIN。用户不方便实测时交付明确的待验证结果，不无限等待。

# Windows 原生握手

从实际工具定义确认能读文件、写独立工程、执行/等待本地进程、读日志和交付文件；无需让用户重复描述这些能力。仅安装时确认Windows宿主与Skill入口/随包资源可读；Python、短ASCII工程目录及构建环境在实际需要时再检查，不因缺少Python阻断Skill加载。能做图片检查、USB串口、多Agent则按需使用，缺少不假装具备。

宿主能自主构建和排错时直接给接口与关键边界；出现具体能力缺口才展开细节，不按品牌人为降级。没有终端/进程结果能力不能宣称已构建；报告具体缺口。模型名称、隐藏记忆或Token读不到写未知，不猜测。

记下本轮用户提供的设备包或材料路径。可用Resolve-Materials.ps1仅解析并在已有WORK保存绑定，缺少02是正常状态；保存失败不应伪装成Skill无法安装。安装到另一个目录后不能靠父目录猜旧材料，不扫描作者全盘，不写死作者盘符。仅安装到此为止，不下载工具、不安装环境、不编译或烧录探针。开始创作后，按运维模块分阶段补缺；有02先复用，没有02再在线获取。

长进程使用独立stdout/stderr日志与退出码；尊重宿主实际权限，短路径需在可写区内选择。不得通过重复启动、扩大权限或修改整机安全策略掩盖路径问题。操作系统沙盒不是默认运行前提。

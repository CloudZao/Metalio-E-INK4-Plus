# 书架搜索

[English](book-search.md)

书架搜索覆盖 `metalio/e-ink/books` 及其全部子文件夹，按文件名关键词匹配，英文字母不区分大小写，不搜索书籍正文。普通书架浏览仍显示当前文件夹；输入空关键词并确认后返回该文件夹。搜索结果沿用分页及封面／列表视图，关键词最多 80 个字符。

## 输入与候选

点击书架搜索框，键盘在原页面底部展开。输入框左侧的放大镜表示搜索，有内容时在右侧显示圆形边框的清除按钮，可清空文字及待选词；清空后按钮隐藏。每次敲入的拼音或英文字母直接显示在输入框；待选片段选中词条后整体替换为汉字、词组或英文单词。

候选栏是键盘顶部部件，首次查询完成后按需展开，不显示“拼音”标题。连续输入期间保持候选栏与键盘布局，复用候选按钮，仅更新变化的文字与翻组状态；等待新结果时不接纳旧候选。候选之间留有间距，不使用单字框。每组按实际字体和可用宽度排列完整词条，不能放入的下一词条整体移到下一组；前后翻组保持词条边界。特别长的单个候选会完整换行，不截断词条。清空组合后，候选栏收起并释放占用的高度。

例如输入 `nihao` 选择“你好”，输入 `zhongguorenmin` 可选择“中国人民”。拼音模式也提供相应英文单词；原大小写键的位置循环切换“中 / abc / ABC”，英数模式提供英文前缀补全，不把英文字母转换为中文。空格在中文待选状态下选择当前组第一个词条，在英数状态下保留所敲单词并插入空格。确认键提交当前中文候选并执行搜索；英数模式确认时保留输入框内的字母。

退格先删除待选片段最后一个字母，随后删除光标前的完整字符。长按退格清除当前待选片段；按下时没有待选片段，则长按清空输入框。移动光标会保留已经敲入的字母并结束该段候选。返回或点击输入框与键盘之外的区域取消编辑并恢复上次关键词。光标常亮、不闪烁。

四行按键区按屏幕高度的 32.5% 计算，宽度适配可绘制区域，左右、顶部和底部保留缩放后的间距；按键沿用系统键盘的布局、边框及按压反馈。

## SD 词库

将词库包解压到 SD 卡，文件位置为 `metalio/e-ink/fonts_ime/zh-CN/pinyin-dictionary.bin`；同目录保留 `pinyin-licenses`。`fonts_ime` 按语言代码分目录，当前中文资源使用 `zh-CN`；键盘布局仍由固件提供。扩展汉字显示仍使用 `metalio/e-ink/fonts/extended-fonts.fontpack`，字形由系统 UI 字库与此补充字库共同提供。词库缺失、不可读或记录无效时会提示，已敲入的字母仍保留，可继续按原文搜索。

字库负责字形，不能直接提供读音、词组或词频。词库按提供的 `misans_25_2.ef` 与 `extended-fonts.fontpack` 字符覆盖筛选，使用 pypinyin 的读音与词组数据及 wordfreq 的词频顺序，包含 41853 个有读音映射的汉字、217016 个中文词组及词组边界前缀、60000 个英文单词。它支持词库内的整词和前缀候选，不提供无限制整句解码、用户学习或联网预测；读音和候选次序不代表逐项人工校对。

词库使用有界二进制索引，文件保留在 SD 卡。每次查询在后台二分查找当前键，只读取不超过 32 KiB 的候选块到 PSRAM，不将整个词库或字体载入 RAM。较新的输入会作废旧查询，待机、卸卡和关闭输入时通过现有存储事务与取消机制收尾。

生成器为 `tools/ime/zh_CN/build_dictionary.py`，可指定字库覆盖和来源文件，输出二进制及来源许可目录。生成依赖仅用于电脑，不编入固件：pypinyin 0.55.0、msgpack 1.1.2，以及固定 SHA256 校验的 wordfreq 3.1.1 发行文件；来源清单见随附 `pinyin-licenses/sources.json`。输出格式版本为 2，词表记录数、字符数和派生改动说明见 `dictionary-report.json`。字形本身不随词库分发。

## 来源与许可

映射与词组读音来自 pypinyin 0.55.0 及其上游拼音数据（MIT）。词频派生排序来自 wordfreq 3.1.1（CC BY-SA 4.0），作者包括 Robyn Speer 及其数据贡献者、SUBTLEX 作者，SUBTLEX 为可免费获取的数据。词库包含字符覆盖、多音读法、词组、词组边界前缀和英文补全；派生数据按 CC BY-SA 4.0 分发并保留映射的 MIT 声明。完整许可随词库包的 `pinyin-licenses` 提供，分发词库时须一并保留；数据许可不改变全部固件代码的许可。

## 代码组织

语言专属实现按 `ime/<语言代码>` 分组：`main/infra/ime/zh_CN` 管理拼音组合与词库读取，`main/ui/common/widgets/ime/zh_CN` 提供中文输入界面，`tools/ime/zh_CN` 提供词库生成工具。通用键盘由公共控件层维护。SD 资源使用 `fonts_ime/zh-CN`。

# 应用商店

[English](app-store_en.md)

应用商店连接云应用商店，在 SD 卡的 `metalio/e-ink/apps/` 中安装 ELF 应用。首页中，“应用商店”排在内置应用后，已安装应用紧接其后，超出当前页时顺延。商店默认以横向单列显示全部应用，每行提供图标、名称、单行简述、版本、包大小和“安装”或“打开”。点击应用行进入详情，信息集中在上方，打开、更新、删除操作固定在底部；页面不显示返回箭头；短按 HOME 或返回键逐级关闭确认框、详情和筛选面板，长按 HOME 直接回首页。从详情打开应用后，返回时恢复原详情。加载、刷新及应用操作结果统一显示在顶部标题区域；下载百分比显示在对应应用右侧按钮内，点击可取消；详情页使用底部主操作按钮显示相同状态。通知不占列表空间，不覆盖应用行。

## 使用

1. 平台需确认设备固定 MAC 已有效绑定，实际板卡和芯片已登记，并发布兼容当前固件和 ABI 的应用；云端部署及存储服务需可用。
2. 商店 URL 在 `main/cloudzao_endpoints.c` 的 `cloudzao_app_store_url` 中管理。
3. 应用列表上方的同栏工具区在左侧显示筛选与应用数量，右侧提供刷新图标按钮。进入或点击刷新时，先读取 SD 卡中的已安装应用，再获取商店目录；刷新保留已有列表、筛选条件和可用范围内的滚动位置。网络请求失败时保留本地应用和已有目录，已安装应用仍可打开。加载中不显示空状态，结果提示自动消失。筛选在标题下悬浮展开带边框的条件面板，不改变应用列表的位置，提供“全部 / 未安装 / 已安装 / 下载中”；点选立即生效并收起，无确认或重置按钮。点击详情中的“检查更新”会重新查询服务器，有更高的兼容版本时在居中弹窗显示新版本号；确认后才下载安装，取消或点击弹窗外区域则保留当前版本。无新版本时提示“已是最新版本”。点击安装状态筛选面板外的任意区域可收起面板。已安装应用可离线运行；服务器下架不会删除本机应用。

商店及详情在前台时持续持有与百问相同的软保网需求，不会因普通空闲策略主动断网，没有安装任务时不阻止正常无操作待机。离页或待机时释放页面需求；在途请求取消并完成文件收尾，唤醒后恢复。手动关闭 Wi-Fi 的设置仍然有效，不会被商店强制打开。

## 文件与更新

每个应用保存为 `metalio/e-ink/apps/<应用名称>/manifest.json` 和 `<应用名称>.elf`，例如 `metalio/e-ink/apps/计算器/计算器.elf`。使用服务器返回的中文应用名称，保留中文和空格，仅替换 FAT 禁用字符、处理前导点及尾部点和空格，并按 UTF-8 边界限制名称长度。同名但不同 ID 的应用不相互覆盖。清单中的 `installedName` 固定本机目录和 ELF 名称，应用更新和语言切换沿用安装名称；应用 ID 与 SHA256 仍用于身份和完整性校验。下载长度、SHA256 和 ELF 结构必须全部校验通过，启动时也重新校验；新 ELF 完整写入后才切换安装清单。清单切换使用现有文件提交与备份恢复机制，旧 ELF 在切换完成后清理。在线目录每页最多 16 个应用，以“上一页 / 下一页”切换，页面只保留当前在线页，不设累计应用数量上限；每个 ELF 最大 32 MiB。SD 卡导出为 USB 磁盘或进入受控待机时，遵循统一 SD 访问许可。

服务端应用包字段 `size` 必须为十进制整数字符串，例如 `"1076"`，不接受 JSON 数字；目录、详情、更新检查和下载清单采用相同规则，范围为 1 至 33554432 字节。分块摘要的 `offset` 同样只接受十进制整数字符串，允许 `"0"`；`index`、`length` 和 `chunkSize` 仍为 JSON 数字。本地安装清单和续传检查点仍保存数值长度。

### 临时文件与恢复

商店工作文件统一放在 `metalio/e-ink/temp/app_store/<应用名称>--<appId>/`。名称过滤 FAT 禁用字符并限制 UTF-8 字节长度，应用 ID 区分同名应用；后续按 ID 复用目录，避免应用改名丢失续传进度。

- `download.part`：下载中的 ELF 数据。
- `download.part.json`：已验证分块的续传记录。
- `download.part.json.part`：续传记录写入时的临时副本。
- `download.part.json.cloud-backup`：续传记录替换时的恢复备份；再次下载时恢复或清理。
- `manifest.json.part`：安装清单提交前的临时副本。

下载失败、取消或离开页面时保留续传数据；重新安装时重新校验完整块。安装成功或删除应用时清理该应用的上述工作文件及空目录，不删除未知文件。临时目录仅可在没有下载安装任务、且相关应用未录音或写入数据时手动删除；删除下载临时文件后需要重新下载。

`manifest.json.cloud-backup` 是安装清单恢复备份。更新时旧 ELF 临时保存为 `<旧sha256>.elf`；新清单提交后清理，提交前失败或取消时恢复旧版本并保留新包续传数据。断电后按清单摘要选择并恢复匹配的 ELF，不能仅凭文件大小判断新旧版本。应用私有状态与恢复备份统一放在 `metalio/e-ink/settings/apps/<应用名称>--<appId>/`，写入临时副本归入商店工作目录。更新保留持久状态；卸载删除该应用的持久状态、恢复备份和写入临时副本，重新安装从初始状态开始。状态删除失败时报告存储错误并保留安装清单，便于重试卸载。文件格式及读写、恢复、清理规则见[私有存储接口](../tools/elf_app/DEVELOPMENT_zn.md#私有存储xz_app_cap_storage)。

## 应用图标

图标随 ELF 一起上传、校验和更新，首页、商店与详情共用包内图标。资源编码、源图要求和构建方法统一见 [ELF 应用开发手册](../tools/elf_app/DEVELOPMENT_zn.md#6-图标与内容资源)。

## 应用接口

第三方应用的入口、兼容性检查、编写规范、构建发布、资源格式与运行限制统一维护于 [ELF 应用开发手册](../tools/elf_app/DEVELOPMENT_zn.md)。接口完整签名以 [app_api.h](../main/app_store/app_api.h) 为准。

### 已开放能力

- 界面与交互：文本、按钮、容器、输入框、系统键盘、进度条及黑白几何绘图；支持应用内返回和推白切换。
- 时间与数据：本地时间、单调计时、前台累计时间、托管定时器及应用私有存储。
- 设备反馈：三轴加速度采样、限时震动及遵循系统设置的按钮点击震动；不提供陀螺仪角速度。
- 音频播放：播放 ELF 内置资源或 SD 文件中的 Ogg/Opus、PCM WAV，支持循环、暂停、继续、停止及进度查询，音量跟随系统。
- 录音与回放：单录音槽，支持开始、暂停、继续、停止保存及状态查询；保存为 16kHz、单声道、16 位 PCM WAV，可直接通过播放接口回放。新录音保存成功后替换上一条，失败或空录音保留原文件。
- 生命周期：退出清理、顶部提示、防自动待机及前后台资源管理。唤醒后等待目标画面物理刷新成功再恢复应用业务；录音在主动待机或离页时结束保存，不自动重新开始。

播放输出固定为 16kHz、单声道、16 位 PCM；录音与应用播放互斥，系统音频优先。正式录音与设置、使用记录共用应用私有数据目录，录制中的文件放在对应临时目录；更新保留，卸载一并清理。参数、路径、返回值及限制统一见[能力接口说明](../tools/elf_app/DEVELOPMENT_zn.md#5-能力接口)。

[重力迷宫](../tools/elf_app/gravity_maze/README_zn.md) 展示绘图、加速度、前台计时、震动与循环音乐；[录音机](../tools/elf_app/recorder/README_zn.md) 展示单文件录音、保存与播放进度。

## 安装队列与资源读取

连续选择应用后按选择顺序安装，每个应用最多入队一次，等待项显示“等待安装”。点击“取消”可移除等待项，或停止当前下载；当前项完成清理后继续下一项。下载期间在应用右侧按钮内显示百分比，每秒最多更新一次；等待安装、校验和取消状态使用同一按钮。点击按钮可取消等待或当前下载，详情页底部主按钮的显示和操作一致。单项失败后继续队列，可重新选择失败的应用。安装及队列等待期间持有禁止待机需求，暂停无操作待机计时。离开商店清空等待队列、取消在途下载并保留可校验的下载文件和检查点；已完成安装保留。取消会等待当前网络等待或 SD 分块读写返回；清单切换前取消会保留原版本，清单已提交后则完成安装清理，不回滚已安装版本。下载使用 256 KiB 的 HTTP Range 分块；中断后重新校验已有完整块，通过的块可以复用，未验证尾部重下。

应用内容可在 ELF 内按需读取，格式、构建与内存限制见[开发手册的资源说明](../tools/elf_app/DEVELOPMENT_zn.md#6-图标与内容资源)。

示例源码与构建方法见 [应用示例](../tools/elf_app/README_zn.md)。

“下载中”筛选显示当前下载、排队等待及校验中的应用，任务完成或取消后自动移出列表。

## 应用启动

启动时居中显示 ELF 图标、应用名称和读取提示，图标与名称间距为 16px，名称与提示间距为 40px。加载页首次上屏且 ELF 初始化成功后才显示应用内容；加载失败时保留加载页并显示错误。入口返回能力不支持时提示应用与当前固件不兼容，并建议升级固件；其他非零入口结果显示启动失败，清理已创建的控件及托管资源。ABI 相同不代表能力相同，应用仍须检查接口表长度、能力位和函数指针；原生 ELF 与固件共享地址空间，错误提示不能隔离任意越界访问。运行区域使用状态栏以下的完整空间，宿主不额外添加应用名称标题；是否显示标题由应用自身决定。

## 应用信息

列表按名称、简述、版本与包大小排列，行间距为 12px。简述使用小一档字号并在单行超出时显示省略号；未提供简述时不增加空白行。详情的信息区域可滚动，包含版本、大小、类别、支持语言、提供者、最近更新时间、应用描述和更新说明，底部操作按钮为独立固定区域，可从信息或操作区开始上下拖动浏览详情；滑动不触发按钮。应用描述和更新说明可分别点击标题收起或展开，默认展开；标题与其他信息项字号一致，正文使用小一档字号。

简述与类别可在服务器独立编辑，无需重新上传 ELF。详情提供中英文描述和更新说明，以及支持语言、提供者和最近更新时间。元数据随安装清单保存，安装后可离线查看。旧清单缺少新增信息时保持可读；在线信息仅在版本和 SHA256 均与本机一致时补全，缺失的信息显示“未提供”。

应用列表上方的同栏工具区提供筛选、当前条件下的应用数量和刷新入口。工具区、列表和详情采用轻微偏移阴影的外框，图标保持 128×128。详情信息与底部操作共用外框，以左右留白的单像素细线分隔。


## 云端通信 / Cloud communication

商店联网获取应用目录、详情和更新，并下载应用包。服务端检查设备绑定和兼容性。安装状态仅由本机维护，不同步安装列表或结果。

## 日志诊断

`AppStore` 记录本地扫描、目录获取、安装、删除和 ELF 加载结果，`AppRuntime` 记录应用入口执行结果。INFO 用于关键开始、完成和正常取消；WARN 用于网络暂不可用或跳过损坏安装项等可恢复情况；ERROR 用于清单格式、完整性校验、存储和启动失败；DEBUG 用于补充校验阶段等细节，默认关闭，构建允许 DEBUG 后仅在诊断时按模块开启。下载不逐块记录进度。

失败记录使用 `operation`、`stage`、HTTP 状态、数值错误码及必要字节数定位问题，不输出服务器 URL、查询参数、请求头、正文或凭据。HTTP 业务错误查看 `operation=http` 的 `http_status`、白名单 `code` 和合法 `request_id`；传输失败查看 `transport_error`；`json`、`schema`、`item` 表示接口数据不符合约定。应用标识仅在格式校验通过后记录，正常取消不作为错误。

只读请求和单块下载最多额外重试 3 次，按 1/2/4 秒加抖动退避；429/503 遵循更长的 `Retry-After`。等待超过 60 秒时停止自动重试，稍后由用户手动重试。409 目录快照过期后重新获取第一页；412 重新获取同一版本清单；416 检查总长度并废弃检查点，不视为下载完成。续传检查点保存包标识、大小、摘要、ETag、块大小和已验证前缀，恢复时重新校验已有块。

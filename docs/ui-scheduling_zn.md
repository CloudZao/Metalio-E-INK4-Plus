# UI 调度与阅读任务

[English](ui-scheduling.md)

## 输入、导航与公共控件

原生和分页滚动条在进入页面及滚动、翻页时显示，停止操作三秒后隐藏；设置、按键说明及阅读字体/目录分页使用相同规则。

触摸采样只记录输入、投递盖板按键边沿并触发早震，同时保留本轮按下起点和最新坐标。分页手势与震动绑定分别使用独立的 USER_2、USER_1 对象标记，避免正文或普通控件被误判成分页列表。下拉手势在按住及松手时均可识别；阅读区下滑优先唤出前光菜单，刷新期间错过采样的下滑也不会误触点击分区。短按、长按和抬起在 UI 任务中按序分发；正文沉浸阅读时，默认音量加、减分别翻到上一页、下一页，长按沿用连翻；目录和设置浮层保留音量控制，自定义绑定优先。同一按键的短按或长按可同时配置全局与局部功能，适用页面优先处理局部功能，其余页面执行全局功能。独立翻页及其全局回退组合通过 `VkKeyScreenDesc` 的独立入口处理，首尾边界仍接管按键，不转为全局功能；“返回＋上一页”保留页面处理后再返回的导航语义，返回与关闭浮层沿用导航入口。未配置长按时仅继承短按翻页，不继承全局操作。页面通过 `VkKeyScreenDesc` 注册默认音量键策略；长按连翻定时器最多保留一次待处理 UI 轮询，翻页回调在 UI 任务执行，执行前重新检查按住状态；页面切换会作废旧页面的积压输入。普通页面短按 HOME 按返回栈逐级返回，返回栈为空时进入应用首页；长按 HOME 默认直达应用首页并清空返回栈。页面专用按键处理先于默认行为，网络密码页、连接状态层和传输预览优先关闭当前层级。边沿队列溢出时取消未完成的按压，防止长按连翻持续运行。

百问 AI 分页保留正文内部空行，忽略文本块末尾空白；仅含留白、分隔线或卡片结构的页面不计为回复页。完整分页、流式追加和历史重放共用此规则。

设置功能页复用统一的功能分区：不同分区之间保留固定间距，分区内的标题、选项与说明紧凑排列。首页样式、刷新模式、系统字体、系统语言、蓝牙模式、前光模式、震动强弱及电源选项使用统一外框分行排列，选中项右侧以圆圈内的实心点标识，选中项文字使用同字号加粗；系统字体选择在显示构造前预读，SD 可用后由现有 UI 轮询异步恢复，不等待联网或版本检查。手动应用及开机恢复成功后，顶部显示“系统字体应用成功”，三秒后自动消失。字体经预览后应用，其余可选项在当前页切换。浅睡待机以信息行显示板级 `config.h` 配置的时长，下方说明读取同一配置。前光亮度加减按钮为圆形，直径略大于进度滑块；测试页调节按钮沿用原尺寸。信息行使用明确的行高，并随换行内容增高；flex 在整行内居中，文字再按字体基线与字形边界校正视觉位置。翻页器的当前连接状态与设备名称在同一行左右显示。设置页触摸与翻页键均按视口切换内容，功能页退出时保留父容器的手势配置。

## 后台任务与结果所有权

UI 回调负责界面状态、任务提交和结果发布。耗时处理应复用 `TaskExecutor::Schedule` 的既有任务域，或复用阅读器已有工作任务；回调中不等待任务完成，不同步读写 SD、重建章节或生成正文位图。工作结果应持有自己的数据，使用会话代次校验迟到结果。UI 队列接收成功后由回调释放上下文；投递失败时由提交方释放或保留重试。

电量由系统监控任务采样，界面读取原子快照。`DisplayLockGuard` 获取失败时调用方立即返回，只有成功持锁的实例执行解锁。UI 回调日志区分排队与执行耗时，正文准备日志区分排队、导航和栅格化耗时；慢调用按五秒限频并累计省略数。墨水屏波形耗时仍由显示层单独记录。

## 阅读绘制与排版

纯文字页与图文混排页的正文共用后台 L8 栅格化和字形解码，统一应用字距、缩进、标题加粗、下划线及抗锯齿。混排页按分页顺序保留插图空位，插图沿用异步加载并按后台生成的坐标显示；栅格化失败时才回退到标签绘制。

横屏及竖屏横排按段处理，逐行按需收紧字距，使行尾文字后的标点优先留在本行。标点默认保留字体原有步进、字形位置及基线，不对段内标点统一贴紧。仅当行尾标点超出正文宽度时，先按需收回末尾逗号、句号或顿号的尾部空白，保留 2px 右侧余量；不足部分再按各处实际可用空白比例分配收紧像素，不额外压缩。紧间隔不压缩，不再以最小间隔限制整行。每个间隔最多收紧约字框高度的 1/12（至少 1px），保留至少 1px 净空及标题加粗余量；无法取得字形边界时不压缩。压缩超限时，横排与竖排均回退到最近的合法断点，避免闭合标点出现在行首或开括号、前引号落在行尾；仅当不可分字符组超过整行或整列容量时按容量拆分。横排英文按单词测宽；为连字符预留宽度后，剩余不超过两个字母时允许在行末添加显示用连字符，超过两个则整词换行。超过整行容量的单词按容量分段；内部英文撇号随单词处理。TXT、EPUB 与 ebook 共用断词判断，显示用连字符不计入源位置或书签摘录。原文显式换行保持不变；段首缩进保持原宽。TXT 预览、章节分页及 EPUB／ebook 分页使用相同判断，正文位图与标签回退按同一规则绘制。阅读设置在“文字排版”行上方提供“对齐方式”，可选左对齐或两端对齐，默认两端对齐；偏好保存及恢复阅读默认设置均包含此项，TXT、EPUB 与 ebook 统一生效。左对齐时横排使用完整正文栏宽并保持左边界，竖排从顶端自然排列，不额外拉伸间隔。两端对齐时，横排非段末行在正文左右边界间对齐，竖排非段末列在正文上下边界间对齐；剩余像素均匀分配到字间，不缩放字形，横排闭合标点前不插入额外空白。段首保留所选字数的缩进，段末及显式换行自然收尾，跨页续行或续列按所选方式对齐；章名保持居中。仅含段末短行的横排页只在两端对齐模式下按最终行宽统一居中。竖排保留标点禁则回退，中英文逗号、句号及顿号均占半个字格；普通空格、不换行空格和制表符按字体步进占位，全角空格仍占完整字格。分页与绘制使用相同占位规则。TTF 分页保留步进缓存，字距安全判断使用与绘制一致的完整字形边界；字体、字号、方向或页边距变化后重新排版。

阅读根容器为信息栏预留固定高度：“全部底部”使用居中的底栏，“上下分栏”使用顶栏和底栏；未选中任何对应信息的栏位隐藏，并将空间还给正文。信息栏使用界面字体，不随正文字号改变。“上下分栏”的上栏文字与系统状态栏文字垂直对齐，上下栏到正文的内侧间隙减半，下栏文字到屏幕边缘的距离保持不变。四边阅读页边距只约束正文可绘制区域。章节标题保留按内容宽度计算的折行，各行加粗居中；章节序号拆行和标题续行均计入分页高度。未设置连续行距时兼容旧档位的 0%、10%、25%、40% 字体行高比例；连续行距使用像素留白。行框统一预留装饰空间，横排容纳 2px 净空与 2px 线宽，竖排容纳 2px 净空、1px 线宽及标题向右加粗的 1px 余量，再按可绘制长度计算行数并均分剩余像素到各行上下。装饰开关不改变行框。横排下划线默认位于本行字形底沿下方，保留 2px 净空，位置偏移可改变此间隔，线宽为 2px；竖排装饰线位于字格右侧，保留至少 2px 净空，标题加粗时同步右移 1px，线宽为 1px。分页、正文位图及标签回退使用同一行布局，短页保留相同的单行几何。段距独立于行距，默认兼容旧标准档 56px，可连续调节并自动保存到 NVS。段距与章后距单独计入，页首不追加段前空白；竖排沿列方向分配。修改段距会重新分页，整页图片书籍仅保存偏好。设置卡片保留固定标题及底部导航，具体设置最多再进入一级，触摸动作选择可多进入一级，底部四项导航的高度和位置固定。正文、信息栏、设置卡片和顶栏的遮挡顺序在建屏时确定，更新尺寸不改变层级；开关设置保留正文抗锯齿状态，未修改排版时复用原页面。开启抗锯齿时退出阅读页，目标页面使用一次 GC16 全刷，不执行推白过渡。

默认阅读卡片显示阅读时长和进度，右上角切换当前页书签。字体和阅读设置分别提供恢复默认；目录与书签列表沿用原有样式。阅读设置采用三列九张卡片，包含方向、底栏、触摸分区、背景、排版、抗锯齿、间距、下划线及翻页。阅读信息可逐项选择，支持“全部底部”和“上下分栏”布局。“上下分栏”将章节名放在左上、百分比进度放在右上、时间和电量放在左下、页数放在右下；布局随阅读偏好保存。“编排中”的状态文字和翻页提示隐藏。触摸分区保留九宫格，动作页左右各五项，浮层让出底部四项导航；恢复默认按钮与阅读设置同尺寸、同圆角胶囊外框及右侧内缩。控件使用黑白样式，数值行不加分隔线。阅读卡片外框由主容器统一绘制，左右各内收 4px，顶部、侧边及导航分隔线为 2px，不绘制底边。触摸分区沿用主外框，不再另画边线。定时翻页与抗锯齿开关按真实状态初始化，整行保持白底黑字，右侧滑钮关闭为白底黑圆、开启为黑底白圆，点击切换当前状态。阅读卡片沿用现有界面字体。标题统一居左并加粗；带外框的选项文字居中，当前选中项加粗。同一页标签共用一条左边线。卡片高度随当前设置项内容变化，超出屏幕时可滚动。数值与单位分别排版。EF 字号和已达到上下限的加减按钮保留黑字白底，以虚线外框表示不可调节。

段距按 2px 在 0–104px 间调节；字距按 1px 在 −2–12px 间调节；行距按 1px 在 0–48px 间调节；四边边距选择上、下、左、右后共用一组加减控件，按 2px 在 0–64px 间分别调节；首行缩进可选 0、1、2、3 字。未单独设置的边继承旧统一像素值或旧档位，修改某一边不改变其余三边；恢复阅读默认设置会同时重置四边。行距仍保留装饰线所需的最小行框，再均分视口余量，因此数值表示首选留白。下划线提供无、实线和虚线；上下位置与间距相同，按 2px 在 −12–12px 间用加减数值行调节。抗锯齿开启后可选弱、中、强；它调整字形覆盖度，不增加预览。自动翻页间隔为 5–45 秒，按 1 秒调节，启用状态仅在当前阅读会话生效。

加减在按住期间只更新控件内数值，松手或取消按压后提交一次。分页、导航游标、正文位图与标签回退共享排版参数；字距、行距、缩进和对齐方式纳入分页缓存指纹；切换对齐方式沿用正文锚点重新排版。阅读偏好保存通过单个异步任务串行执行，同类待写快照合并为最新值；触摸分区使用独立的串行保存任务，合并待写配置，并在任务退出前完成 NVS 提交。字体选择以最新请求为准，加载期间重新选择原字体可覆盖待处理请求。字体和目录列表将上下滑动作为整页切换手势，不显示拖动过程；字体每页最多九项，目录每页九行，末页保留空白；多页列表保留滚动条指示当前位置。字体列表外框固定绘制，内容在内层裁切。多页列表独占纵向手势，空列表和不足一页的列表保留下拉菜单手势。状态栏底线宽度跟随父容器，适配横竖屏。

## 阅读导航与首屏恢复

阅读翻页、目录跳转、阅读进度和书签定位统一使用 `RequestReaderNavigation`。`book_nav` 持有请求状态并统一调度前台导航、当前章节排版和回收；正文工作模块只接收任务、准备页面并交回结果，不反向调用导航模块。UI 创建独立导航游标，后台任务通过独立只读句柄读取索引和页面，完成目标章节分页、字体预热及正文位图后，UI 才发布当前位置与像素。页面直接发布已有 TXT 预览、物化页或章节缓存，不再保留额外的当前页副本；书签请求只复制目标位置。失败或作废结果保留原阅读位置。同章相对翻页可接续已准备的预取页；跨章提交时清空原预取链，后续页面从当前章的分页文件重新准备，避免独立分页缓存交叉接管。前台准备或等待绘制期间的相对翻页输入直接消费，不进入积压；仅后台预取不阻止正常导航。绝对跳转保留最新目标，长按连翻不补发错过的整秒步进。

开机书库预热任务的优先级低于前台阅读和字体任务，SD 访问竞争时优先准备正文。后台编排不禁用书签、自动翻页和章节导航。TXT 预览以原文字节范围保存和定位书签；上下章提交相对目录增量，在前一个结果提交后计算下一目标。字号、排版、待机和离页会取消旧任务；结果由代次校验后发布。字体使用者退出后才验证和切换新字体，失败保留原字体与偏好。推白方向按稳定正文位置判断，并随正文像素发布。

首屏恢复与目录结构分离：打开 TXT 时直接读取续读字节附近的一页，EPUB/EBOOK 只解析锚点所在的原始正文并生成一页预览；不等待全书扫描或本章总页数。压缩正文可能仍需从所在文件开头读到锚点，超长物理正文和旧页码转换仍可能增加打开时间。结构就绪前，章节页数显示 `--/--`，EPUB/EBOOK 全书百分比显示 `--%`；TXT 按源字节提供进度。尚不能定位的章节名暂不显示。

首屏绘制后，既有低优先级排版任务先读取与字号无关的 `.rsi` 结构缓存；缓存未命中时扫描目录锚点和正文长度，再排版当前章节，并按最新正文锚点接回当前页。缓存按书籍大小、修改时间、格式及解析版本校验，记录数、位置范围和校验值不合法时重新扫描。缓存写入失败不影响当前正文；失败的结构或分页任务保留可读预览。缓存更新使用临时文件和现有存储提交机制，正文与续读记录不作为缓存清理。

扫描结果由后台暂存对象持有，UI 只接收完成的结构和分页；结构准备期间的翻页会保留首次请求并中止后台任务，待其在安全点退出后准备目标页，不等待整书扫描或当前章节完整分页。排版任务在提交时固定取消代次，取消后的结果不能覆盖阅读位置；连续输入不积压，导航空闲后继续后台排版。TXT 保留解码缓冲、标题识别状态和字节位置继续扫描；EPUB/EBOOK 保留已经完成的源文件，最多重新扫描当前未完成文件。待机和离页先取消任务，再关闭文件句柄；恢复后继续未完成的工作。结构完成前允许翻页、书签和原生目录导航，短历史内可回退；EPUB/EBOOK 的任意百分比跳转等待完整结构，失败时保留当前页。

EPUB 的相邻有效目录目标构成阅读章节，允许同文件细分和跨文件延续；重复目标共用范围，缺失锚点退回对应文件开头。无原生目录的 EPUB/EBOOK 按正文文件或章节分页，界面保留“暂无目录”。TXT 目录最多保留 8,000 项，超出部分仍可在末章继续阅读；无可识别目录时保留逐页流式阅读，不计算全书页数。

前台导航使用独立游标，只排版目标章节，成功后发布正文、章节页码及按内容累计位置计算的全书百分比；失败或取消保留原正文与位置。切章超过短暂延迟后显示“章节内容加载中…”，完成、失败、新请求、待机或离页时清除。正文按可用内存沿阅读方向逐页预取。最近一页之后，同一工作任务优先准备阅读方向上的相邻章节分页，再补入口页栅格和更远页面。分页与栅格独立保留，命中部分结果时直接补绘已准备游标，不重复导航；源会话导航结束后，完整像素缓存可直接发布。相邻章节由独立游标准备，完整分页保存在 SD，RAM 仅保留页面及索引窗口；匹配的导航请求在发布时接管所有权。取消和过期结果不改变阅读位置。同一设置页的后台更新在数值调节松手后合并执行。字号变化只更新现有控件，不重建字体列表或重置滚动条显示计时；目录内容、页数或选择模式变化时重建列表。字号或视口变化只重排当前章节，已有全书页数缓存不再读取或写入。字体或几何改变须等待现有字体使用者退出，再应用新参数；TXT 当前页预览也在后台计算。阅读背景按几何复用，背景像素和正文合成在工作任务中生成。阅读背景与下划线只影响绘制，开关不改变正文边距、视口、行数和分页。方格以约 32px 的目标间距均分固定内容区，四边完整，边格与内格的像素取整误差不超过 1px；内容区尺寸不变时，翻页不改变格数。

排版结果保留在固定交接槽，完成后通过公共完成通道唤醒 UI；页面生命周期处理当前页面更新，离页后的延后清理继续推进，不依赖普通消息队列容量。当前章节分页存于 SD，内存保留两页正文及固定索引窗口；导航共享只读目录范围，避免逐页复制整书目录。分页完成后关闭写句柄，使 FatFS 文件长度对独立读句柄可见。游标交付结果前关闭文件句柄，保留已物化页面，延迟回收不会持有 SD 句柄或删除新会话的分页文件。

可选图片、正文及相邻章节准备共用一个执行权，按图片或页面规模保守估算，不逐笔预留分配额度。公共图片解码、正文栅格化和字体加载暂停新的可选工作，预计工作空间不足时请求回收缓存。持有模块立即或在安全点释放闲置资源；当前页、正在使用的字体实例和解码缓冲仍由原生命周期管理。回收代次阻止迟到的可选结果重新入缓存。内部空闲 RAM 须保持固件安全底线，总量或连续空间不足时仍按原有失败或降级路径处理。

进度保存提交独立 POS4 快照，同一本书尚未执行的保存合并为最新快照；重新打开时也会读取尚未落盘的快照。排队写入及资源回收通过 `SdAccessDeferredTransaction` 预留 SD 事务，卸卡须等其完成。退出前提交最终进度，后台析构不再保存旧位置。`SaveProgress()` 返回成功表示快照已接纳；实际写盘失败另有错误日志。 TXT 保存原始字节位置及段首标记，EPUB/EBOOK 保存原始正文编号、块编号和 UTF-8 偏移，图片书保存原始页图位置。快照带文件大小、修改时间、格式、解析版本与完整性校验；验证失败不覆盖旧记录。旧 POS1/2/3 仍可读取，时长字段按原版本恢复；旧章节页码仅在恢复时按旧物理章节边界转换成正文锚点。旧 TXT 优先采用原字节锚点，其次借用仍匹配旧排版的 `.idx`；均不可用时按百分比近似定位附近段落，不能保证精确恢复。缺少文件身份或旧排版信息的旧记录无法验证原文件未变化。BKM1 书签保持原始正文区间，旧展示页码不参与定位。旧固件不识别 POS4；回退固件前应备份原续读记录。文件替换、解析版本不匹配或损坏的 POS4 会阻止续读，须由用户处理原记录后重新打开。

导航、正文准备和存储写入按上述边界移出 UI 执行路径。书签添加和删除提交独立快照，在 `Storage` 保存成功后接入结果；离页后仍完成写入，失败保留原快照。书籍解析、SD 访问和墨水屏波形仍各有完成时间，硬件驱动内单次阻塞访问需要返回后才能取消。

## 图片交付与取消

详情封面使用一个工作者，只保留最新待处理请求；离页或重新请求会取消在途解码，结果由 UI 回收后才处理下一张。文件打开等不支持取消的底层调用返回后检查取消状态，不提前释放仍在使用的资源。正文插图只有在任务接纳后才交出请求，分配或创建失败会给对应图片槽显示现有的加载失败提示。A2UI 图片在提交时绑定页面代次，工作者和交付端通过原子代次检查丢弃旧结果。

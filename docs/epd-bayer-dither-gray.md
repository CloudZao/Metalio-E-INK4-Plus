# 墨水屏网点模拟灰色背景

> **阅读抗锯齿已改为真 4 灰**（`epd_gray_aa` + `epd_lut_4gray` + `SSD1677_EPAPER_REFRESH_GRAY`）。本文仅描述首页卡片等仍用 Bayer 网点模拟浅灰底的路径。

本文说明首页应用卡片如何用 **Bayer 有序抖动（网点）** 在 **1bpp / I1** 墨水屏链路上模拟浅灰底，而不启用真 4 灰阶 LUT。

实现位置：`main/display/screen/home_screen/home_screen.cc`（`GrayDitherImg()` + `kBayerThreshold`）。

---

## 为什么需要网点

| 路径 | 能力 | 灰底怎么办 |
|------|------|------------|
| 当前 I1 + OTP 局刷 | 每像素只有黑 / 白 | `#AAAAAA` 等灰色会被量化成白，实色灰底无效 |
| 真 4 灰（RED+BW + lut_4G） | 白 / 浅灰 / 深灰 / 黑 | 可用实色灰，但与现有差分局刷冲突，全刷约数秒 |

在 **不改驱动、不加大帧缓冲、继续走局刷** 的前提下，用黑白像素按比例打点，人眼远看近似灰色。

---

## 原理

### 1. 有序抖动（Ordered dither）

对每个像素取 Bayer 矩阵中的阈值，与阈值比较：

```text
black = (Bayer[y & 3][x & 3] < kBayerThreshold)
像素 = black ? 黑(0x00) : 白(0xFF)
```

矩阵值范围 **0～15**（4×4 Bayer），分布均匀。阈值越大 → 黑点越多 → 观感越深。

本仓使用的 4×4 Bayer：

```text
 0  8  2 10
12  4 14  6
 3 11  1  9
15  7 13  5
```

### 2. 平铺贴图

- 生成 **8×8** 的 `LV_COLOR_FORMAT_L8` 小图（64 字节，与 4×4 矩阵对齐重复一次）
- LVGL：`bg_image_src` + `bg_image_tiled`，铺满圆角卡片
- 所有卡片共用同一张静态图，几乎不占额外 RAM

### 3. 与真灰阶的差别

| | 网点灰 | 真 4 灰 |
|--|--------|---------|
| 像素 | 仍是黑白点 | 控制器灰阶电压波形 |
| 近看 | 可见点阵 | 均匀色块 |
| 刷新 | 走原 I1 局刷 | 需 4 灰 LUT，通常全刷 |

## 取值范围与效果

### `kBayerThreshold`

| 项目 | 说明 |
|------|------|
| 类型 | `constexpr int` |
| 合法范围 | **0～16**（与矩阵最大值 15 对应） |
| 判定 | `Bayer < threshold` 为黑 |
| 黑点占比 | 约 **threshold / 16** |

| `kBayerThreshold` | 黑点占比 | 观感（经验） |
|-------------------|----------|--------------|
| **0** | 0% | 全白，无灰底 |
| **1** | 6.25% | 极淡，几乎看不见 |
| **2**（当前） | **12.5%** | 浅灰、网点较疏 |
| **3** | 18.75% | 略深一档 |
| **4** | 25% | 中等浅灰 |
| **6**（曾用） | 37.5% | 接近 `#AAAAAA` 观感，偏密 |
| **8** | 50% | 中灰，点很密 |
| **12** | 75% | 深灰 |
| **16** | 100% | 全黑 |

调参建议：

- **要更淡 / 更疏** → 减小阈值（如 `2` → `1`）
- **要更深 / 更密** → 增大阈值（如 `2` → `3` 或 `4`）
- 改完需重新编译烧录；图只在首次 `GrayDitherImg()` 时生成一次

### 其它相关常量

| 常量 | 当前值 | 作用 |
|------|--------|------|
| `kDitherW` / `kDitherH` | 8 | 平铺图尺寸（字节 = W×H） |
| `kCardRadius` | 16 | 卡片圆角，与灰底一起裁切 |

一般不必改宽高；改 Bayer 阶数（如 8×8）需同步换矩阵与阈值上限。


## 局限

1. **不是真灰**：放大或近看能看到黑点。
2. **圆角 / AA**：边缘半透明像素在 I1 上仍会量化，可能略有锯齿或脏区变大。
3. **对比度依赖屏与波形**：同样占比在不同面板上深浅可能不同，以实机为准。
4. 若以后上真 4 灰，可改为实色 `#AAAAAA` 并去掉本网点逻辑。

# SD 存储与数据管理

**中文** | [English](sd-storage.md)

产品根：`/sdcard/metalio/e-ink/`（[sd_paths.h](../main/infra/storage/sd_paths.h)）

| 路径 | 用途 |
|:---|:---|
| `.../books` | 电子书正文，支持分类子目录；兼容保留旧旁路文件 |
| `.../wallpaper` | 壁纸与关机图 |
| `.../fonts`、`.../fonts_ttf` | 阅读 `.ef` 字体、拓展字库 `.fontpack`、`.ttf` / `.otf` 字体 |
| `.../fonts_ime/zh-CN` | 中文输入法词库及许可 |
| `.../settings` | Wi-Fi 配置；`books/` 保存阅读进度、时长和书签；`sysmgmt/logs/` 保存运行日志和崩溃转储 |
| `.../temp/books` | `cache/` 保存可重建的封面、页数和 TXT 索引；`work/` 保存分页工作文件 |
| `.../temp/bwchat` | `images/` 保存聊天图片；`messages/` 保存当前启动周期的会话 JSON，开机清空 |
| `.../temp/wallpaper` | `work/` 保存图片处理与预览工作文件；`meta/` 保存壁纸名称信息 |
| `.../temp/transfer/work` | 传输应用的下载和预览工作文件 |

挂载 SD 卡时补齐应用目录、清理分页工作文件并恢复中断保存的壁纸备份；HTTP 下载和 JPEG 解码在首次使用时清理各自的临时文件，清理失败时不创建新工作文件，后续调用可以重试；壁纸保存和删除前清理本模块的工作文件。不扫描书库、壁纸库或辅助数据缓存库，不执行自动搬迁，也不读取或更新迁移完成标志。已有辅助文件继续在原位置读写：书籍旁的旧文件优先，其次兼容新目录中的分组文件和平铺文件；只有不存在已有数据时，才在新目录创建文件。壁纸名称信息兼容原图旁的 `.meta.json`、`.meta` 和新目录中的已有文件。新建的书籍辅助数据和壁纸元数据按哈希首位分入 `0`–`f` 子目录，限制单目录文件数量。旧文件不会自动整理，使用电脑手动整理前应备份原数据。阅读进度和书签不随 `temp/` 清理；封面与索引可重建，壁纸名称信息丢失时回退显示文件名。百问新会话直接使用新目录；旧会话缓存和旧日志目录不自动搬迁。用户主动改名、移动或删除书籍和壁纸时，同步维护对应辅助数据。`ui/` 和已有 `recordings/` 保持原样，不再默认创建录音目录。根目录保留中英文上传说明文件。

书架、云书库和文件传输页共用书籍与壁纸删除处理。删除书籍会清理关联进度、书签、封面、索引及其固定名称备份和最近阅读记录，并扣减该书对首页累计时长及读完数量的贡献；按日期保存的阅读历史保留。同名其他格式书籍仍存在时保留共用的旧封面。正在打开或阅读的书籍拒绝删除；删除成功后取消尚未提交的进度写入。单书删除按已知路径清理，不遍历书籍目录；带未知会话编号的旧分页工作文件不在此时查找，删除所属目录时一并清理。递归删除目录时先处理书籍，再删除旁路文件。删除壁纸同时清理名称元数据、保存备份和对应启用设置。通过电脑 U 盘直接删除文件不执行这些业务清理。

ELF 安装、续传与私有数据的目录及事务由[应用商店](app-store.md)管理。SD 导出为 USB 磁盘前须停止设备侧文件活动，电脑端写入后安全弹出；直接在电脑上删除文件不会执行固件业务清理。

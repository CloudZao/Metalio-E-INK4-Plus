# 多板型硬件测试用例与结果

[English](hardware-test-matrix.md)

用例按静态检查、主机测试、整包构建及硬件测试区分。已有结果仅适用于其对应固件；源码变化后按影响范围重新验证，待执行项不得视为通过，主机测试和构建不能替代设备验收。

范围覆盖板型构建、启动、显示、输入、SD、USB、摄像头取消、内存及待机恢复。用例覆盖按改动域映射；未接入代码行覆盖率工具，不宣称分支或语句覆盖率。模拟输入不等于物理输入验证，日志成功不等于屏幕视觉正确。

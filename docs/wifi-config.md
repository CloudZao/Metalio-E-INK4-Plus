# Wi-Fi 配置与 SD 同步

设备将 Wi-Fi 列表保存在 NVS 和 SD 卡的 `metalio/e-ink/settings/wificonfig.json`。开机同步在网络启动前完成，运行中修改卡内文件不会立即导入。

## 文件格式

文件使用 UTF-8 编码，可带 BOM。设备写入时使用两空格缩进和换行，便于阅读和编辑；读取时也兼容单行 JSON。示例：

```json
{
  "version": 1,
  "networks": [
    {"ssid": "Home", "password": "example-password"},
    {"ssid": "Guest", "password": ""}
  ]
}
```

列表最多 10 项，首项为默认网络，SSID 不得重复。SSID 为 1–32 字节；密码为空表示开放网络，否则为 8–63 字节，或 64 位十六进制 PSK。长度按 UTF-8 字节计算。字段必须完整且类型正确，不接受未知字段、重复字段、内嵌空字符、非法编码或超出 8192 字节的文件。

清空配置使用 `{"version":1,"networks":[]}`，不要以空文件表示清空。

## 同步规则

- 开机文件存在且合法：完整替换 NVS 和内存中的网络列表。换卡后按卡内配置覆盖。
- 文件不存在：从当前 NVS 创建文件。无卡、挂载失败和读取失败不按文件缺失处理。
- 文件内容非法（包括空文件或超出大小限制）：保留 NVS，并用有效 NVS 配置覆盖修复 SD 文件。NVS 不可用时不覆盖；写卡失败时保留待同步标记并重试。无卡、读取失败或路径不是普通文件时不触发内容修复。
- 新增、修改密码、删除、清空和调整默认网络：先保存 NVS，再写 SD。清空写入合法空列表。
- 配置和待同步标记使用同一个 NVS 记录保存。SD 写入失败时保留标记；下次开机优先将 NVS 写回 SD，成功后清除标记，避免旧文件恢复已删除的网络。**存在待同步标记时，即使换卡也先将 NVS 写入当前卡。**
- 运行期间每 30 秒重试待同步写入；待机、SD 不可用、USB 存储启用或切换期间延后处理。USB 停用并恢复本机挂载后，在下一次重试时写入。不会在重试时导入卡内配置。
- SD 写入使用同目录 `.tmp` 临时文件和 `.bak` 备份文件；完整写入、刷新和关闭后替换正式文件。开机正式文件缺失且存在备份时恢复备份。异常断电仍可能损坏 FAT 文件系统，不能保证两种介质同时提交。

旧版 NVS 网络列表会迁移到完整配置记录，提交成功后清理旧凭据键。日志区分同步方向、校验原因和读写阶段；网络序号从 1 开始，字段校验区分缺失、重复、类型和长度错误，不输出密码或其他凭据值。

## 数据保护

JSON 中的密码为明文。能读取 SD 卡或通过 USB 访问该文件的人可以读取网络凭据，请妥善保管 SD 卡及其备份。

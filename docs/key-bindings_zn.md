# 按键与手势

[English](key-bindings.md)

在“设置 → 按键与手势”查看“功能说明”和注意事项，再在“自定义功能”选择按键，进入全屏页后选择短按或长按并设置功能。功能选项以黑底白字表示当前绑定。页面末尾的“重置按键功能”可恢复初始绑定，不改变手势开关。

页面首个分区为“手势开关”，“手势识别”默认开启。右滑执行底部上页键的默认功能，左滑执行底部下页键的默认功能，均不受按键自定义配置影响。关闭后只停用左右滑动翻页，底部按键仍按现有绑定工作；上下滑动及下拉菜单不受此开关影响。滑条、文本输入及有横向滚动范围的控件优先处理自身拖动。

功能说明支持上下滑动翻页，右侧滚动条显示当前页位置。

全局功能用于音量、返回、前光和电源等通用操作。局部功能只在适用页面生效：上一页、下一页由当前页面处理；快捷进入 AI 应用于首页和阅读页面；按住录音用于支持语音输入的 AI 页面；阅读设置用于正文；打断播报用于助手对话页面。

可组合返回与上一页、进入与退出待机、进入 AI 与按住录音、阅读设置与打断播报，由页面或状态决定执行哪个动作。短按已绑定翻页且长按未配置时，持续按住沿用页面连续翻页；长按另有绑定时优先执行该绑定。

单独绑定快捷进入 AI 应用只打开应用；与按住录音组合后，长按进入应用时可继续按住说话，松开结束。

必须保留至少一个实体按键退出待机，以及至少一个按键关机。退出待机只能绑定实体按键的短按，不能绑定底部三个触摸键或任何按键的长按；按住录音只能绑定非电源键的长按。更换必留功能前先设置其他按键。硬件或手势不支持的选项使用虚线框；移除最后一个必留绑定时，会提示先绑定其他按键。重复功能确认后可以共用。开机及电源键硬件强制关机不受配置影响。

功能按板型提供。3.97 英寸板型没有前光，菜单和说明不显示前光开关、调亮、调暗；4.7 英寸板型提供这些选项。

## SD 配置

按键绑定与手势开关仅保存到 SD 卡的 `metalio/e-ink/settings/key_bindings.json`，不写入 NVS。缺文件时创建初始配置；有效文件在挂载后读取并应用；SD 不可用时使用内存初始配置。无卡时用户修改仅本次运行生效，插卡后以卡上配置为准；卡上缺文件则创建初始配置。

文件采用与 Wi-Fi 配置一致的两空格缩进 JSON。仅读取 `settings/key_bindings.json` 及其备份；两者均不存在时创建默认配置。

配置读取、默认文件创建和保存由后台存储任务执行，不阻塞界面操作。写入前载入当前介质的配置，保留未修改的按键绑定和手势开关。保存完成后应用本次修改；保存期间不接纳另一笔修改，离页后仍完成已提交的保存，排队期间切换介质则取消该笔写入。保存使用暂存与备份替换，失败保留原绑定。FAT 替换不保证断电原子性。无效配置回退到整套初始配置，保留原文件供修正。

JSON 使用 `version: 1`，`gestures_enabled` 控制左右滑动识别，缺省为开启。按键对象为 `boot`、`power`、`volume_up`、`volume_down`、`previous`、`next`、`home`。各对象包含 `short`、`long` 功能标识数组，空数组表示不执行操作。标识定义见 [key_bindings.cc](../main/infra/storage/key_bindings.cc)。每个手势最多两个功能，且须属于支持的组合；未知版本、未知功能、缺项、非法组合和违反必留条件的文件不应用。

配置与校验由 `infra/storage/key_bindings` 管理；公共输入分发负责动作及松手收尾；板级代码按有效绑定准备实体键唤醒输入。界面与 JSON 使用同一套校验，不可通过编辑文件绕过硬件及手势限制。
